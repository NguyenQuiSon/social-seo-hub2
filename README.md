# Topic 17 – Social Signals & Social Media Optimization cho SEO

Trang web demo tương tác cho Topic 17 (Nhóm 17, môn SEO).

## Nội dung
- Khái niệm nền tảng và vai trò của social sharing / social signals
- Tác động trực tiếp vs gián tiếp của mạng xã hội đối với SEO
- Case study giả định: Website A (bán mô hình 3D) kèm mô phỏng phễu
- Chiến lược tích hợp website và mạng xã hội (4 bước)
- Demo thẻ Open Graph (xem trước và sao chép mã meta)
- KPI, sai lầm cần tránh, câu hỏi thường gặp

## Cách chạy
Mở file `index.html` bằng trình duyệt. Không cần cài đặt thêm.

## Đưa lên GitHub Pages
1. Tạo repository mới trên GitHub và tải toàn bộ file trong thư mục này lên (nhánh `main`).
2. Vào **Settings → Pages**.
3. Ở mục **Build and deployment**, chọn **Deploy from a branch**, nhánh `main`, thư mục `/ (root)`, rồi bấm **Save**.
4. Sau khoảng 1–2 phút, trang sẽ có địa chỉ `https://<tên-tài-khoản>.github.io/<tên-repo>/`.
